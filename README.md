# Responsive Layout

A fully responsive, mobile-first webpage built from scratch using HTML and CSS. The layout adapts across small, medium, and large screen sizes using media queries.

## Built With
- HTML
- CSS (mobile-first approach)
- Media queries

## Features
- Mobile-first design — styled for small screens first
- Breakpoints for tablet and desktop screen sizes using `min-width` media queries
- Clean, structured layout that reflows naturally across devices

## What I Learned
- Writing CSS with a mobile-first methodology
- Using `min-width` media queries to progressively enhance layouts
- Building a responsive page from scratch without a template
